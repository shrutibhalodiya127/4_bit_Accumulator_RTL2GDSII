# RTL to GDS-II: 4-bit Accumulator Implementation

This repository documents the end-to-end VLSI design flow for a sequential 4-bit accumulator that calculates the sum of the first 'N' integers.

## 🚀 Project Overview
The design was implemented from RTL development to Static Timing Analysis (STA) using a combination of Xilinx and Synopsys EDA tools.

### Problem Statement
1. Design a sequential 4-bit accumulator for the summation of the first N integers using Verilog HDL.
2. Generate the GDS-II layout and report area, frequency, and power consumption.

## 🛠️ Technologies and Tools Used
Simulation & Verification: Xilinx Vivado
Logic Synthesis: Synopsys Design Compiler (DC)
Physical Design: Synopsys IC Compiler II (ICC2)
Static Timing Analysis: Synopsys PrimeTime (PT)

## 📊 Design Specifications & Results
Based on the final implementation reports:
* Total Cell Area: 167.909 µm²
* Total Chip Area: 182.212 µm²
* Setup Slack: +2.533 ns (MET)
* Total Power: 5.28e-05 W
* Standard Cell Library: saed32rvt_ss0p7vn40c (32nm)

## 📁 Repository Structure
* rtl/: Verilog source code (n_bit_adder.v)
* tb/: Testbench and verification files (n_bit_adder_tb.v)
* constraints/: Design constraints (n_bit_adder.sdc)
* scripts/: TCL scripts for synthesis and physical design
* reports/: Timing, area, and power reports generated by Synopsys tools
  
## 🔍 Functional Verification
The design was verified in Xilinx Vivado with the following test cases:
* Case 1: n=10, Final Sum = 55
* Case 2: n=12, Final Sum = 78
* Case 3: n=15, Final Sum = 120

## 🎨 Physical Design Gallery
* Floorplan: T-shaped core orientation with 8.5% utilization.
* Placement: Optimized cell placement based on powerplan.
* Clock Tree: Synthesized clock tree with optimized latency.
* GDS-II Layout: Final routed design ready for fabrication.
